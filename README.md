# Montgomery County Police Department Use of Force Analysis
### Research conducted in conjunction with MCPD and MCG TEBS Data Innovation Team

Accountability demands are increasing for public safety officials, which is complicated by multi-source reporting and inconsistent metrics. To address that, I built an automated ETL pipeline using Apache Airflow to consolidate and reliably ingest data from these sources. From there, I’m developing a dashboard that gives department leadership a clearer, real-time view of use-of-force trends across Montgomery County.

This repository contains the sum total of all data, ingestion techniques, pipeline information, and completed analysis that went into this project.
